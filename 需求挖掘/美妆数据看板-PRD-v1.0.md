> 版本 v1.0 · 2026-09-26
> 状态：经用户多轮反馈后的重写版。替代此前 v0.x 原型阶段口径。
> 本版核心变化：从「示例数据原型」转向「真实数据驱动的联动工作台」。

## 〇、本版相对此前的根本变化

| 维度 | 此前（v0.x 原型） | 本版（v1.0） |
|---|---|---|
| 数据 | 写死的示例数据 | **真实采集**，代码驱动的数据流 |
| 筛选条 | 摆设，不与数据联动 | **真联动**，筛选即重算 |
| 商品行 | 无链接、无图 | **真实链接可跳转 + 真实商品图** |
| 数据量 | 每类目 10 条 | **类目下全部商品（翻页拉满）** |
| 环比增速 | 标「待积累」 | **类目级取罗盘现成环比；商品级靠每日快照计算** |
| 策略台 | 示例卡片 | **按四段真实分析（CR4/CR10/玩家结构/供给侧/GO-NOGO）** |
| 代码 | 单文件空壳 | **模块化分层（采集/口径/视图/前端）** |

**两条强制红线（贯穿全篇）**：
1. 业务需要的数据必须通过技术得到 + 业务口径计算，**禁止胡编乱造**。拿不到就标「待积累/待接入」，不造假数字。
2. 代码不是工作台空壳。采集脚本接入真实平台数据流，业务数据经计算后链接到列表对应位置，**全程代码完成，禁止 AI 手工搬运数据**。

## 一、需求背景

业务人员每天要做选品决策：哪个类目在涨、值不值得进、竞品在卖什么、要不要做。现状是数据散落在罗盘/蝉妈妈/FastMoss 多个平台，字段过载、口径打架，靠人肉拼接。要一个**每天自动跑完选品判断链路**的工作台，数据真实、筛选联动、结论可追溯。

## 二、需求目标

做一个数据驱动的美妆选品工作台，覆盖「找机会 → 看市场 → 看竞品 → 下决策」四步，前端保持现有 Stripe 白色风格不变，后端为模块化采集+计算管道。

## 三、全局共享规则（所有看板通用）

### 3.1 筛选条（全局统一组件）

**市场维度**：含具体国家 + **「全部」**（所有国家数据汇总展示）。
- 市场=国内 → 数据源罗盘/蝉妈妈；市场=海外 → 数据源 FastMoss（自动切换）；市场=全部 → 各源汇总并列。

**品类维度**：罗盘式级联，hover 逐级展开（一级→二级→三级→四级），**支持多选**。
- 类目树列全罗盘所有品类（19 个一级类目全列），但仅「个护家清→个人护理→面部洗护/眼部护理」有真实数据，其余标「数据待接入」。

**周期维度**：近1天 / 近7天 / 近30天。**周期切换必须联动所有数据**（重新取数/重算）。

**联动铁律**：筛选条与数据强绑定。筛选条是数据的查询条件，任何筛选变化都触发对应数据重新计算/渲染。默认（不筛选）= 全部类目的汇总。

### 3.2 数据源分工（口径红线）

| 用途 | 主源 | 说明 |
|---|---|---|
| GMV/市场规模/类目环比 | 罗盘 | 官方区间值，权威 |
| 带货结构/成分卖点/受众画像 | 蝉妈妈 | 预估口径，不作 GMV 主口径 |
| 海外数据 | FastMoss | 待实测接入 |
| 竞品筛选 | 飞瓜 | 同事负责 |

**不同源数字不混加**。区间值（罗盘 GMV）禁止精确聚合。

### 3.3 增速口径

| 层级 | 口径 | 来源 |
|---|---|---|
| 类目级环比增速 | 直接取罗盘 `out_period_ratio`（现成字段） | 罗盘类目概览 |
| 商品级增速 | 本期近7天 vs 7天前近7天（每日快照积累计算） | 快照表 |
| 成分增速 | 同一成分 7天前 vs 今天的排名/关联商品数变化 + 新上榜单标 | 蝉妈妈成分榜快照 |

### 3.4 更新频率
增速看板每日刷；类目趋势/成分库/成分榜每 7 天刷。

## 四、板块详细需求

### 板块① 全球数据看板

#### 1.1 增速产品看板（每日刷新）

| 项 | 需求 |
|---|---|
| 模式 | **取消自用密度模式**，只保留「结论模式」——自用也看结论 |
| 结论板块 | 大而显眼。含：① 七天内增速最快的产品 ② 该产品 GMV 增速 ③ 销售国家 ④ 销售价格（带货币符号 ¥/$） |
| 商品榜 | 每个类目只放 **TOP3 增速产品** |

### 板块④ 初始策略台（改名，原「初步判断策略」）

**业务目的**：业务人员看完前面板块后，想进某增长快的类目，看了该类目热门成分和头部商品后，来策略台**筛选想做的类目，系统给出该类目能否进入的结论**。

| 项 | 需求 |
|---|---|
| 筛选联动 | 筛选条与策略分析**联动**（当前不联动） |
| 分析维度 | **必须按 PRD 实现，当前缺失**： |

**AI 结论四段**：
1. **市场规模**：该类目 GMV + 当前增速
2. **市场竞争程度**：
   - 集中度：CR4（前4占比）、CR10 占比
   - 玩家结构：国际大牌 vs 新锐品牌 vs 白牌 占比
   - 决策标准：CR4>60% 且无明显细分机会→难进入（除非供应链/渠道优势）；CR4<40% 且有细分空白→有机会。综合 CR4/CR10+玩家结构给结论
   - 分类标准：罗盘商品榜有「知名品牌/非知名品牌」筛选，知名品牌含国际大牌+新锐，非知名≈白牌；国际大牌 vs 新锐按「国际知名品牌」维度细分（标准待细定）
3. **供给侧结构**：
   - 价格带分布：哪个价格带玩家最多（最卷）/哪个空白但有需求/TOP玩家定价策略（日常价 vs 大促价、折扣力度）
   - SKU矩阵：TOP玩家结构（引流款低价高ROI + 利润款高客单 + 复购款会员/套装）
   - 决策标准：目标价格带竞品数<10 且 月销量>1000万→有机会；利润空间（1-成本占比）>50%→可以做
4. **初步结论**：GO/NOGO + 理由 + 细分方向 + 客单价带（目标价格区间）

**可视化**：关键数据尽量可视化，联动结论。

**技术说明**：策略台真实实现需接 LLM API 做综合研判（输入结构化数据→输出 GO/NOGO 结论）。本版先用**规则引擎**实现确定性部分（CR4/CR10/价格带/SKU 可算），LLM 综合结论作为增强位预留。

### Voyager 关键参考（已沉淀）
- **飞瓜《2026 抖音个护家清品类洞察》**：个护品类 TOP5 销售额集中度 6.93%（妇炎洁1.92%/参半1.61%/白云山1.52%/半亩花田0.99%/茵缇玛0.89%），头部壁垒薄弱、新品牌切入机会充足；品牌分级参考「国民品牌（蓝月亮/活力28/心相印/维达，长期心智）vs 新锐」。
- **成分词口径可借鉴**：报告「高增长品类分析」直接给「成分词+销售热度」（如洗发皂：侧柏叶/草本/何首乌/黑灵芝/人参），可作成分提取词典起步。
- **黄金3s台词口径**：报告按月度给品类高频台词，与蝉妈妈「黄金3秒」模块互证。

### 数据量与性能（用户疑虑 → 架构回应）
- **快照只存最小字段**（商品id+类目+日期+金额区间中值，~100字节/条），2 类目 ≈ 15MB/年，不存图/标题全文。
- **快照滚动窗口近 90 天**，环比只需「本期 vs 7天前」，旧快照归档。
- **增量更新**：每天只追加当天数据，不重算历史。
- **前后端分离计算**：采集/计算在后端跑，前端只读算好的视图模型 JSON，浏览器不实时算全量 → 数据量再大前端也不卡。
- 本轮只跑通 2 类目验证链路，不重构。

## 六、非功能需求

- **模块化代码**：采集 / 口径计算 / 视图模型 / 前端 分文件分层，多层级目录，规范引用
- **数据流代码驱动**：采集→计算→链接到列表位置，全程代码完成，禁止手工搬运
- **前端样式不变**：保持现有 Stripe 白色风格、导航（4 主导航+更多下拉）、级联筛选、红涨绿跌
- **可追溯**：每个数字可点开看来源、口径、样本量、数据截止日
- **失败降级**：登录失效/接口报错→暂停+通知，不补假数据
