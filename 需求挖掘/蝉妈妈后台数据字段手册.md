## 〇、一页看懂：蝉妈妈 vs 罗盘，谁管什么

两个平台都统计抖音电商，但**口径和强项完全不同**，不能混用：

| 维度 | 抖音罗盘 | 蝉妈妈 | 用谁 |
|---|---|---|---|
| **GMV 主口径** | ✅ 官方全渠道区间值（权威） | 预估口径（区间+精确值并存，但非官方） | **罗盘** |
| **带货结构**（直播/视频/商品卡拆分） | 弱 | ✅ 商品详情页直接给拆分占比 | **蝉妈妈** |
| **关联达人/视频数** | 无 | ✅ 商品/品牌/达人都给 | **蝉妈妈** |
| **受众画像**（性别/年龄/地区/城市等级） | ❌ 只有本店 | ✅ 品牌/达人详情页直接给 | **蝉妈妈** |
| **成分/功效/卖点** | 弱（只有商品标题） | ✅ **美妆属性分析模块专门做** | **蝉妈妈** |
| **黄金3秒台词/高光话术** | ❌ 无 | ✅ 全平台聚合 | **蝉妈妈** |
| **类目 cid 体系** | ✅ 完整（7447 节点 4 层） | 用一级类目名筛选，无 cid | **罗盘**（取类目结构） |
| **数据精度** | 区间值（官方） | 区间值 + 预估精确值（非官方） | 看场景 |
| **时间粒度** | 日/周/月，最长回 266 天 | 昨天/7天/30天/90天 | 罗盘更长 |

**铁律（沿用你的数据采集手册）**：蝉妈妈的 GMV 数字（区间列/精确列）一律不作主口径——区间列封顶 100w+，精确列只覆盖直播+视频带货，对货架驱动品牌低估 5-15 倍。**「多少钱」只信罗盘，「谁在卖、怎么卖、用户是谁」信蝉妈妈。**

## 一、接口基础与反爬

| 项 | 情况 |
|---|---|
| 业务 API 域名 | `api-service.chanmama.com` |
| 列表主接口 | `POST /v6/product/search` —— **请求体加密**（`is_encrypt:true` + base64），network 抓不到明文 |
| 列配置接口 | `GET /v1/common/tableFields?table_type=<类型>` —— **不加密**，返回该列表可配置列的字段名 |
| 埋点 | `analysis.chanmama.com/v1/jsonp` · `analysis.chanmama.com/v1/report` |
| 取数方式 | **不要试图解密请求体**。直接从 DOM 读渲染结果，或用 `tableFields` 拿字段名 |
| 登录态 | cookie 会话，过期让用户在浏览器手动登录 |

### 已知非加密 GET 接口

```
GET /v1/common/tableFields?table_type=product_search    # 商品库可配置列
GET /v1/product/categoryV7                              # 商品类目
GET /v1/product/hotWord                                 # 商品热搜词
GET /v1/product/attributeCategoryType                   # 属性类目类型
GET /v1/search/condition/list                           # 筛选条件
GET /v1/user/info · /v1/user/extraInfo                  # 用户信息
```

## 十三、已知坑与禁令

| # | 坑 | 处置 |
|---|---|---|
| 1 | 业务接口请求体加密 | **不要试图解密**。从 DOM 读渲染结果，或用 `tableFields` 拿字段名 |
| 2 | 区间列封顶 100w+ | ❌ 禁止聚合（100w+ 可能是 100 万也可能是 1000 万） |
| 3 | 精确列只覆盖直播+视频带货 | ❌ 不可作品牌/品类 GMV；✅ 可作带货结构分析 |
| 4 | 品牌详情页是全品牌全类目 | ❌ 不可作单一品类数据 |
| 5 | 免费版为预估口径 | 标「待验证」，不要硬猜 |
| 6 | 品牌词单独搜索是语义匹配 | 必须配合品类关键词或品牌筛选器 |
| 7 | 评论 API 对 web 端 403 | 评论只能 DOM 抓（走手册里的 scrape_comments.sh） |
| 8 | 浏览器单例 | 不并行操作；不关用户 Chrome |
