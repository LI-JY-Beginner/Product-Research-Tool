## 3. 爆款拆解怎么拆的（重点）

- **量**：不是每个产品都是 10 条。7 个链接本月**没有带货视频**（飞瓜 `带货视频 = 0`），页面如实标注「该链接本月无带货视频」，不编数据；1 个链接只有 4 条就拆 4 条。合计 **216 条**拆解。
- **筛选**：排除 粉丝 >100 万、品牌自营/旗舰店账号、标题含 9.9/免单/抽奖 的福利款；**中腰部（1–50 万粉）优先**。被排除的仍列出并打标「已排除：原因」，共 75 条。
- **拆法（2026-09-26 改版）**：**直接取视频文案原文来分析，不拆画面**。
  - 痛点 / 卖点 **不再是词表命中的孤词**，而是从文案里抽出的**原句引用**（例如「眼周松垮有泪沟鱼尾纹的姐姐们」，而不是「鱼尾纹 / 泪沟」）。文案里没有就如实写「文案未直接点名」，**不用评价词云去兜底冒充实测**。
  - 每条给出**文案逐句拆解表**：每句原文 + 类型（钩子 / 痛点 / 功效 / 成分 / 人群 / 场景 / 背书 / 转化）+ 它在干什么。
  - 新增 **目标人群 / 使用场景** 两列，同样取文案原句。
  - 仍保留框架类型与「亮点 / 转化点 / 爆点」三句，并附**文案原文 + 抖音原视频直链**可点回去复核。
- **如实标注的缺口**：**未做 ASR 逐句口播转写**。文案是达人在抖音发布的视频文案（含话题标签），**不是口播逐字稿**；痛点/卖点/人群/场景全部来自这段文案，文案没写的就留空，不靠词库猜。每页都写明了这一点。

## 4. 取数口径

- **池子**：飞瓜「商品销售榜」`#/product-rank/index?tab=product`，类目筛选 **个护家清**（用户指定的类目方式），关键词 8 个（眼油/眼部精华/眼精华/眼霜/眼膜/眼贴/眼周/眼部护理），周期**月榜 = 近 30 天**。
- **定稿**：41 条 → 标题眼部校验 → 同品归一化去重（32 字标题 Jaccard ≥ 0.72）→ 37 条 → 按「销售额档中位 → 销量档 → 浏览量」降序 → **TOP30**。
- **卡片层**：每个商品开一次详情页读渲染 DOM（品牌/小店/分类/上架/佣金/好评/销售额·销量·订单·浏览·转化/视频·直播·达人数/渠道占比/带货方式占比）。
- **深度层**：**全量 30 个链接**，每个取 30 条带货视频 + TOP20 达人 + 集中度 + 达人类型 + 内容词云。
- **画像/评价层**（本轮新增）：`portrait/goodsTransactPortray`（性别/年龄/地域/兴趣/消费层级/价格偏好）+ `GetGoodsCommentPolarityStat`（好评/中评/差评计数 → 差评率）+ `GetGoodsCommentWord`（16 类评价词云）+ `getSegmentCommentsV2`（评价原文）。
- **图片**：`assets/products/<gid>.*`＝**真·商品主图 800×800（28/30）**；`assets/covers/` 为兜底视频封面；`assets/video/`（216 张视频缩略图）。
  （2 个数据贫瘠链接无评价数据 → 取不到商品图，如实留空，不塞占位图。）

### 口径的已知限制（汇报时不要说成精确值）

1. 飞瓜只给**档位**（100w+ / 10w+ / 2500-5000），不给精确销售额与销量 —— 排序用档位中位数。
2. **价格是推算值**：用「佣金金额 ÷ 佣金率」反推，无佣金标注的链接显示「无佣金标注，无法反推」。
3. **卡面图先看 `assets/products/`**：真商品主图取法见坑 4/坑 8；取不到时才退回 `assets/covers/` 的视频封面，页面上角标会明确写「商品主图」还是「带货视频封面」。
4. 抖音 CDN（`*.douyinpic.com`）封面 URL 部分签名会 403；每个 URL 里带飞瓜兜底地址 `?$$dyurl=https://logocdn.feigua.cn/...`，实测稳定 200，已优先使用。
5. 商品详情主接口是 `Encrypt:true` 加密的，卡片层只能读 DOM；而**带货视频/达人/词云、受众画像、商品评价这几组接口是明文且不需要 ts/sign**（只认 gid），可以单页/单标签页直接重放。
6. 「备案成分」「工厂/配赠」飞瓜没有对应字段，页面写的是「飞瓜属性 tab 未给，需以抖店详情页为准」，**不编造**。

## 7. 复用这条链路必须知道的 9 个坑

1. **飞瓜页面有隐形 `el-loading-mask` 遮罩**，`elementFromPoint` 永远命中它 → 点击静默失效。先 `document.querySelectorAll('.el-loading-mask,.v-modal').forEach(e=>e.remove())`，并对目标元素派发完整 PointerEvent 序列（`tmp/_helper.js` 已封装）。
2. **同一个标签页里连续刷多个商品，画像/评价接口会「假返空」**：前 5–9 个正常，之后全返回 `null`（HTTP 仍 200）。**必须一个商品一个独立标签页**（`navigate newTab:true` → 取完 `close_tab`），见 `12c_collect_profile4.py`。
2b. **16 类分类词云（`GetGoodsCommentWord?wordType=X`）必须先把该链接的「商品评价」tab 点开**，否则直接 fetch 会返 `Code:500 接口不存在或不被支持`（看起来像接口没了，其实是上下文没建）。顺序：开页 → `install` helper → `click_tab_full('商品评价')` → 等 6–7 秒 → 再调接口，见 `12d_collect_cats.py`。
3. **SPA 陷阱**：`navigate` 到只改 hash/query 的 URL 不会重新渲染。要么 `newTab:true`，要么先落在别的路由再 `location.hash=...`。
4. **商品主图不能从 DOM 拿**：飞瓜商品详情页的 `img.img-product` **从头到尾都是 1491B 的 base64 占位图**（高频轮询 90 秒、抢在 onerror 前读都拿不到真 URL）。真图在**加密接口** `GetGoodsCommentList` 的响应里（`Data.Items[0].GoodsInfo.CoverUrl`，800×800 `p*-aio.ecombdimg.com/img/ecom-shop-material/...`）。取法见坑 8 + `scripts/15_fetch_product_images.py`。达人头像/视频封面仍走别的链路，不受影响。
5. **脚本里别清下载失败的文件**：`os.remove()` 批量删会触发「批量删除确认」而中断整条链路。用「先下 `.part`，成功再 `os.replace`」。
6. **跨文件跳转在本地 `file://` 下不可靠**（用户实测「变成一大串代码」）——所以本模块收成单文件 + hash 路由。以后不要再拆回多文件。
7. **`screenshot` 指定 selector 会报 `element has no layout box`**，用区域截图 `{x,y,width,height}`；且多标签页并存时区域截图可能截到另一个标签页，验证 DOM 时优先用 `evaluate` 而不是看图。
8. **★ 飞瓜接口返回是密文，裸 `fetch()` 拿不到明文**：页面用的是自己的 fetch 包装（请求发出 → 解密 → `JSON.parse`）。你自己 `await fetch(...)` 拿到的 `Data` 是一串 Base64 密文。**解法：钩住 `JSON.parse`**（`tmp/_jp_hook.js`），在「解密之后、渲染之前」把明文截下来，再正则取字段。顺序：开页 → 装钩子 → 点「商品评价」tab 触发请求 → 等 11 秒 → 读 `window.__jp` → 正则抠 `CoverUrl`。这条路对任何加密接口都通用。
9. **抖店（`haohuo.jinritemai.com`）在本机走不通**：浏览器导航被主机安全策略拦（`SENSITIVE_APPROVAL=TIMED_OUT`），`curl` 页面是纯 JS 渲染（11.9KB 无图），`promotion/pack` 接口有反爬（200 但 0 字节）。**别再往这条路上花时间。**

## 8. 铁律

- **所有品牌一视同仁**：白云山不单独高亮、不做对标基准，与其他品牌完全同等呈现。
- **页面版式固定**：入口页是商品卡墙（购物软件式卡片），点开才是该链接的详情页；**入口页不放品类级结论速览**。
