一、需求背景

用户本人每天要做美妆选品判断，工作台上挂着罗盘、蝉妈妈、FastMoss、飞瓜等一堆平台后台；选品同事要用他产出的结论做下一步调研。但真实卡点不是没数据——原话：「虽然我有很多平台的后台，但这些平台有太多数据字段了」。同一指标在多个平台之间口径打架，42 个字段里有 15 个要靠人手工填，没人替选品同事把结论说完。

造成的影响：用户每天花大量时间在多平台间切换对数、手工补字段，「每天更新」靠手工根本不可持续；同事拿到的不是结论而是半成品表格，还要二次加工；AI 大赛路演现场没有解释口径的机会，界面如果像内部工具，评委不会记住。

同时这个需求天然是双场景：业务实效是及格线（功能必须真跑通，不能是演示数据），视觉是入场券（路演 + 现场演示，不能做得太丑）。两者共用同一份真实数据，不能互相替代。

事实来源：① 9/24 飞书会议纪要（含原始录音转写）② 现有工作台发布版源码实测盘点（42 字段中 15 个手工填，占 36%）③ 需求洞察 v1.1 §1~§3；15 项口径已于 2026-09-25 逐项与用户确认闭环（见沟通记录）。

二、需求目标

总目标：让选品判断链路每天自动跑完——默认只给结论、每个数字可下钻到原始来源，同一份数据同时撑住「自用高密度分析」和「路演 30 秒看懂」两种读法。

用户结果衡量指标统计口径预期方向目标值
用户无需每天切换多平台手工对数，打开看板即看到当日增速结论增速看板每日自动更新成功率观察方式：连续 7 天检查快照表，实际成功写入天数 ÷ 7↑待基线确认
同事拿到的是可直接引用的结论，不再二次加工手工补数字段占比需手工填写的字段数 ÷ 看板总字段数（现状 15/42 = 36%）↓待基线确认
路演现场评委不用听解释就能看懂「它解决什么」路演模式首屏结论数 / 可切换性观察方式：路演模式下首屏只呈现结论卡片与机会点；同一份数据一键切回密度模式↑待基线确认

  • 竞品分析（产品/用户/视频三维度）：由同事独立开发，本工作台只留导航位，不承担其数据通路（飞瓜账号易被顶号，风险随模块转移）

  • 上线排期与灰度：已定「先出 PRD + 线框稿，再谈排期」，不写上线计划

3.1 数据源口径分工

维度取值说明
GMV 主口径抖音罗盘（官方区间值）「多少钱」只信罗盘；罗盘金额全为区间值（如 ¥1,000万-¥2,500万），不假装精确
带货结构 / 成分卖点 / 受众画像蝉妈妈「谁在卖、怎么卖、用户是谁」信蝉妈妈；其 GMV 精确值为非官方预估，一律不作主口径
成分关联（国内）蝉妈妈国内产品扒蝉妈妈数据得关联成分；海外无类似平台，本质都是从商品标题/详情页提取主要成分——本期先把国内做好
竞品筛选飞瓜同事负责的竞品模块使用，本期不涉及
市场规模 · 国内罗盘店铺榜 / 商品榜 TOP200与海外口径分列展示
市场规模 / 商品榜 · 海外FastMossFastMoss 主要覆盖海外市场（TikTok Shop）；字段可获取性待实测；国内与海外绝不混合相加
铁律罗盘区间值与蝉妈妈预估值绝不混加同一指标只有一个口径，谁说了算写在口径徽章里

3.2 增速计算口径

维度取值说明
商品增速公式本期 7 天累计支付金额 ÷ 前段 7 天累计支付金额 − 1罗盘 GMV 本身是 7 天累计值、每日更新；取两段不重叠 7 天窗口做比值（如 9/18–9/24 vs 9/11–9/17），等价于「当日 ÷ 前 7 日同日」的会议口径
可回溯范围自然日最长回 266 天（罗盘实测）第一天就能出增速，不需要空跑攒历史
类目 cid个护家清=5 / 个人护理=1000003462 / 面部洗护=1000003463 / 眼部护理=1000003469罗盘类目树实测值（四级：眼霜=1000003550 / 眼膜=1000003551 / 眼部精华=1000003553 / 眼部护理套装=1000003554；洁面=1000003481 / 面膜=1000003482 / 面部护理套装=1000003483 / 化妆水·爽肤水=1000003476 / 面霜=1000003478 / 面部精华=1000003479），类目选错 = 数据整体错位
类目趋势环比直接用罗盘类目概览自带环比字段8 个类目指标全部自带「较上周期」环比，不用自己算
CR4 / CR10用 TOP200 榜单数据自己算TOP4 / TOP10 支付金额占比，源头可追溯，不依赖外部现成口径
供需比罗盘 demand_supply_rate 字段原值增速产品看板商品行的「供需比」列直接用罗盘字段，标来源，不自算

3.3 更新频率

维度取值说明
增速产品看板每日刷新「每日快照」的真实含义 = 每天重新取一次 7 天累计值并写入快照，不是每天攒一个单日值
类目增长趋势每 7 天刷新会议敲定节奏，与增速看板不统一
成分增长榜 / 成分库每 7 天刷新同上
采集通道浏览器自动化（kimi-webbridge，带登录态）罗盘签名每次变、蝉妈妈请求体加密，必须走真实浏览器；登录失效则暂停并通知手动登录，不硬闯

3.4 展示模式

维度取值说明
自用密度模式（默认）高密度表格、多列对比、筛选器全展开服务用户本人的日常研判；Kibana 式可折叠分区 + 可下钻关联展示

3.5 已确认口径（2026-09-25 与用户逐项确认，别改错）

维度取值说明
成分增长榜增速成分自身增长率：同一成分 7 天前 vs 今天的排名 / 关联商品数变化看的是成分自身的增长率，不是销售额增速；「新上榜成分」（今天上榜、7 天前没上）单独标记，不与环比数字混排

【页面元素】

3、筛选条：「市场」（国家/地区）+「品类」级联筛选——品类按罗盘分类逻辑，从一级（个护家清）→ 二级（个人护理）→ 三级（面部洗护 / 眼部护理级）

4、类目分组区：按当前筛选命中的三级类目分组卡片（如「面部洗护」「眼部护理」），各展示本组增速 TOP3 商品

5、商品行：名次与名次变化、是否新上榜标记、商品名 + 主图、品牌（独立列）、价格带、支付金额区间、环比增速、所属类目、供需比

6、表头列序：名次 | 商品 | 品牌 | 价格带 | 支付金额区间 | 环比增速 | 所属类目 | 供需比 | 口径

7、口径徽章：每个增速数字旁的口径标签（来源 / 时间窗 / 区间值标记 / 数据截止日）

8、「数据截至」标识：本页数据的截止日期

【交互说明】

1、切换「市场」或「品类」筛选 → 自用结论板块与下方类目分组区同步刷新为对应市场/品类数据

2、点击口径徽章 → 弹出该指标的口径说明（定义、样本量、数据截止日、来源）
