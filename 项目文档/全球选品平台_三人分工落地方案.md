## 零、三个先说的判断

**判断一：你们的方向是对的，但现在是一辆没有装货的车。**
工作台的工程完成度很高（5 视图 / 9 条洞察规则 / 8 个数据源台账 / 33 字段 / 双云表 / 规则健康度自检），这部分 AI 组同事做得相当专业。但库里现在全是 `DEMO0001` 开头的**示例数据**。而 9 条规则里有 3 条（改良机会 / 可落地 / 空白赛道）依赖「差评关键词、备案路径、宣称支撑难度、预估成本、与我方 SKU 重合度」这些**只能人工标**的字段——这些字段现在全空，所以这三条规则**必然是 0 命中**。
> **结论：9/28 前最高杠杆的事不是加功能，是把真数据和大选字段灌进去，让 9 条规则全部能跑出东西。**

**判断二：你负责的部分，恰恰是别人抢不走的那一块。**
远程分工最怕"三个人做同一件事"。按"谁能拿到什么资源"切，护城河很清晰：

| 人 | 独占资源 | 不可替代性 |
|---|---|---|
| **乾颖** | 自家店铺罗盘账号、千川投放后台、达人资源与发片表、TikHub、飞书自动化链路、**真实业务场景** | 别人拿不到这些登录态和业务判断 |
| **选品专员** | 品类/成分/备案/成本/功效宣称的领域知识 | 别人不知道「配方工艺」和「独家原料」该怎么分档 |
| **AI组** | 工程能力（采集管线 / 引擎 / 部署） | 别人写不动这 4000 行 |

一句话：**AI 组搭骨架，选品专员定标准，乾颖灌真血肉并把它讲成一个能打的故事。**
比赛评分最看"真实性"和"闭环"，而这两样正好卡在你手上——所以你的份额一点都不轻。

**判断三：现在最大的缺口是"后半段"，而它正好是你的地盘。**
我把工作流 V2.1 的八个章节和工作台逐个对了：

| 工作流章节 | 工作台现状 |
|---|---|
| 一 · 市场规模与趋势 | ✅ 有（全球看板 / 类目热度） |
| 一 · **竞争集中度 CR4/CR10** | ❌ 源码里 `CR4` 一次都没出现 —— 决策标准缺一条腿 |
| 一 · **流量结构** | ❌ 无（上一版分析里就指出这节被误删了） |
| 二 · 产品核心要素 / 成分 | ✅ 有（品类与成分库） |
| 二 · **SKU 矩阵与定价 / 货架策略** | ❌ 无 |
| 三 · 竞品商品榜 | ✅ 有（榜单中心，含达人密度榜） |

| 三 · **达人资源清单** | ⚠️ 只有「关联达人数」一个数字，没有达人台账 |
| 四 · 用户调研（小红书 / 外部口碑） | ⚠️ 小红书只是「评价来源」的一个选项，没有采集管线 |

## 二、乾颖的三个模块 · 具体操作手册

### M5 ｜口碑真数据供给 —— 你的最高杠杆动作

**为什么是它**：9 条规则里「改良机会」只依赖一个字段——`差评关键词`。这个字段是 `src:'manual'`，任何平台都导不出来。现在全空，所以这条规则一定是 0 命中。**只要把它填上，平台立刻多出一条能输出的洞察规则。** 而这份数据只有你能拿。

**产出目标**：不少于 **30 个真实商品 × 好评/差评关键词**。

**操作步骤（照着做）**：

1. 打开 `compass.jinritemai.com`（抖音罗盘）→ **商品** → **体验** → **用户原声**
2. 导出自家 TOP 10–15 商品的原声数据，再补 15–20 个主要竞品的评价（竞品的可以走第三方或已装的抓取技能）
3. 让 WorkBuddy 帮你结构化，直接复制这段话：

> 我把抖音罗盘「用户原声」导出的文件放在 `<路径>`。
> 请按这个格式整理成 TSV：**商品名称 \t 商品ID \t 评分 \t 评价数 \t 好评关键词 \t 差评关键词 \t 评价来源**。
> 要求：① 好评/差评关键词各不超过 5 个，必须是从原文里真实出现的词，不许概括不许编；② 差评里优先保留能指向"可改良"的具体问题（如漏油、辣眼、搓泥、难冲洗），不要保留"太贵了"这种不可改良的；③ 输出前给我看 3 行样例，确认后再出全量。

4. 打开线上工作台 → 口碑诊断视图 → **导入数据** → 粘贴 TSV
5. **验收**：去「机会洞察」看「改良机会」是否从 0 命中变成 ≥ 3 个。

> ⚠️ **开工前必做**：先微信问 AI 组一句话——"第二张表 `ZOiFonS5w7psZlgM5kJjiD` 现在的字段名列表给我一下，我要对齐 TSV 表头。" 别自己猜字段名，这是远程协作最容易返工的地方。

这是**加分最多**的一块，因为它同时修掉了两个问题：

- 补上工作流第三/六/七/八章（视频拆解、达人资源、投放测试、规模化）—— 平台目前完全空白

**你要做的**：定义字段（你最懂业务），AI 组建表建视图。把下面这张表直接发给他：

| 字段 | 类型 | 说明 |
|---|---|---|
| 素材ID | 文本 | 唯一键 |
| **关联商品ID** | 文本 | **外键，关联主库的商品ID——这条最关键，没它两张表连不上** |
| 平台 | 单选 | 抖音 / TikTok |
| 视频链接 | 文本 | |
| 达人抖音号 | 文本 | 你建联要用 |
| 达人粉丝量 | 单选 | 1万以下 / 1-10万 / 10-50万 / 50万以上 |
| 视频时长 | 数字 | 秒 |
| 是否挂车 | 单选 | 是 / 否（**不挂车的不进 ROI 评级**） |
| 钩子类型 | 单选 | 痛点 / 反常识 / 提问 / 场景 / 剧情 |
| 0-3秒话术 | 长文本 | 逐字 |
| 3-10秒核心利益点 | 长文本 | |
| 10-15秒转化强化 | 长文本 | |
| 15秒后信任背书 | 长文本 | |
| 场景 | 单选 | 卫生间 / 卧室 / 户外 / 化妆台 |
| 角色 | 单选 | 素人 / 达人 / 剧情 / 测评 |

**数据源分工**：
- **自家素材**：你的「达人发片表」（飞书）+ 千川后台 → 直接导出

**推荐安装这个技能**（比自己写脚本省你两天）：

> **`douyin-jiexi`**（skill_d：skill_2097291922769104896）
> 发一个抖音分享链接，自动完成 下载 → Whisper 口播转写 → VLM 画面理解 → 逐帧 OCR → 生成结构化笔记。
> **有省钱方案**：方案 B 纯口播走本地 Whisper + 免费视觉模型，**零成本**；方案 A 画面有料的走付费 VLM，约 0.3 元/条，且执行前会先给你确认。还有先预览再入库的设计，不会瞎写。
> 这正是上一版分析里我建议你们自研的"视频拆解 skill"，现成的，直接装。

配套的还可以装 **`douyin-transcript-imitation`**（skill_2095706615499956224），它带 **10 维度敏感词检测**——正好接住上一版说的合规红线（眼护/护肤在抖音是强监管，话术直出脚本会下架封号）。AI 初筛 + 你人工终审。

### M7 ｜把平台讲成一个故事 —— 作品的临门一脚

比赛作品好不好，**一半在工程，一半在 90 秒能不能让人听懂**。这块建议由你主导，因为你最懂业务价值点在哪。

要产出 4 样东西：

1. **90 秒 demo 脚本**（固定路径，不许临场发挥）
   建议路径：`全球看板（看全球覆盖）→ 机会洞察（引擎自动跑出 4 类机会，报数字）→ 点开一个命中商品看完整档案（含成分/口碑/可行性）→ 跳素材与达人视图（这就是我们接下去要投的方向）→ 收口讲 ROI 闭环`
2. **答辩 deck** —— 建议装 `business-html-deck`（skill_2096363609409032192，HTML 演示，键盘翻页、响应式）或 `enterprise-ppt-guard`（skill_2100436084917194752，出 PPTX 且会先给你大纲确认）
3. **README / 一页纸**：说清 数据来源 → 字段契约 → 9 条规则 → 谁负责什么
4. **每周自动化上线** —— 你已经有的 lark-cli 飞书链路直接复用，不用新搭：
   - 每周一自动生成「上周新入库商品 + 新命中的机会 + 素材 ROI 排名」推送到飞书群
   - 这一条的好处是：**答辩时你可以说"它已经在每周跑了，不是演示品"**，这句话杀伤力很大

## 三、选品专员的两个模块（你要拿去对齐的）

**M3 · manual 字段填写规范** —— 目前是 0，直接卡死 3 条规则。需要他给出：
剂型、概念标签、质地描述、技术壁垒（无壁垒/配方工艺/独家原料/专利技术）、备案路径、宣称支撑难度、预估成本、与我方价格带匹配、与我方客群匹配、与我方 SKU 重合度、决策状态。
重点是**每一档要有明确判定标准**，否则三个人填出来三套，数据就废了。

**M4 · 9 条规则阈值卡** —— 现在代码里的阈值是拍的（`WIN_MIN_GROWTH=60`、`NEW_MIN_GROWTH=100`、`NEW_MIN_SOLD=1000`、`ING_MIN_GROWTH=80`…）。**这是评委最容易问倒的地方**："60% 这个数哪来的？" 需要专员给依据（比如"过去 6 个月 TOP100 商品增速中位数是 38%，取 1.6 倍作为机会线"）。有了这层依据，作品的专业度会再上一个台阶。

另外请他拍板一件小事：**韩国市场怎么办**。平台自己标得很诚实——`MARKET_FLOW.韩国 = 'no'`（TikTok Shop 韩国站未开通，只有 Hwahae/Olive Young 的成分口碑名次，拿不到销量，所以三条规则算不出来）。
> 我的建议：**不要掩饰，要主动说出来**。这份「数据源地图 + 覆盖率标注 + 规则健康度自检」的设计是整个平台最成熟的部分之一，敢承认自己算不出来的市场，反而比假装全覆盖更可信。

## 五、接口契约 —— 远程三人协作的生死线

三个人异地远程，最大的风险不是谁偷懒，是**接口漂移**。务必在今晚把这三份东西冻结：

| 契约文件 | 谁负责初稿 | 冻结时间 |

## 七、风险红线（提前说，别踩）

1. **韩国别吹** —— 人家问"韩国数据怎么来的"，答不上来就是硬伤。诚实标注反而加分。
2. **蝉妈妈配额** —— 55 次/月且月度更新，一次性规划调用，千万别写成每天自动跑。
3. **示例数据 vs 真实数据** —— 代码里有「数据标记」开关，答辩务必切到真实；但**建议保留一份示例模式作为 fallback**，万一现场真实数据出问题还能演。
4. **合规** —— 所有出街话术过一遍敏感词检测（AI 初筛），你人工终审。眼护/护肤这个是会封号的。
5. **别选 Temu / Amazon** —— 平台的源全是 TikTok Shop 生态；现在叫"全球选品"但实质是 TikTok Shop 六国 + 中日韩口碑，**对外口径要诚实说清边界**，评委一定会问。
6. **你自己的时间** —— 你是实习生，白天要上班。上面给你的 M5/M6 里，凡是重复的、批量的活都丢给 WorkBuddy 跑，你只做"判断"和"验收"这两件贵的事。
