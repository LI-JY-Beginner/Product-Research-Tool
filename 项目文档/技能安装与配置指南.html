三、⚠️ 三条必须提醒你的风险

  1. Cookie 是明文存在技能目录里的 - 抖音：douyin-jiexi/scripts/cookies_netscape.txt - 小红书：xhs-title-collector/.cache/cookies.json → 别把这两个文件同步到公司网盘 / GitHub / 发给别人。 也不要用你的主账号。

  2. 强烈建议用备用账号 抖音 Cookie + 小红书登录态挂在脚本里，属于平台不太喜欢的用法。用一个专门的运营小号，别用你自己常用的账号，避免被风控。

  3. 采集合规 内部竞品分析一般没问题，但产出物对外使用前必须脱敏（用户昵称、头像、ID 去掉）。这一点跟你之前那份工作流的口径保持一致。

五、一条省钱提醒

douyin-jiexi 有两档：

方案 适用 成本
方案 B 纯口播视频（画面没啥信息） ≈ 0（本地 Whisper + 免费视觉模型）
方案 A 画面有料（榜单卡片、教程截图、产品图） ≈ ¥0.3/条，执行前会先问你

按你们的情况，护肤/个护类带货视频大多是口播为主，所以默认走方案 B 就行，40 条视频成本基本为 0。只有遇到那种"满屏成分表/对比表"的才需要方案 A。

2026-09-24 实测更新 · 本地 Whisper 已真正跑通 191 秒音频 → 132 段 → 耗时 50 秒，纯 CPU、0 元、无限流。

⚠️ 纠正一个说法：之前 Whisper 没装好时，我用「抽帧 + 智谱视觉模型读抖音烧字幕」临时顶替转写，并把它叫作"方案 B"——那只是权宜之计，不是方案 B 本尊。现在 Whisper 就位，方案 B 恢复完整形态。
