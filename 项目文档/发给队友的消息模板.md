## 消息三 · 发给选品专员（manual 字段 + 阈值卡）

```
【需要你出两个东西，这两个东西没出，平台有 3 条规则永远是 0 命中】

背景：9 条洞察规则里，「改良机会 / 可落地 / 空白赛道」这三条依赖的字段
（差评关键词、备案路径、宣称支撑难度、预估成本、与我方SKU重合度）都是
src=manual —— 任何平台都导不出来，只能人工标。现在这 15 个 manual 字段全空，
所以这三条规则必然 0 命中。

要你出两个东西：

【一】《人工字段填写规范》——9/23 晚前
这 15 个字段，每个都要写清"什么情况填哪一档"，最好配一个例子。
否则三个人填出来三套标准，数据就废了。

剂型（水/乳/霜/油/膏/喷雾/粉）
概念标签
质地描述
技术壁垒（无壁垒 / 配方工艺 / 独家原料 / 专利技术）
好评关键词
差评关键词
评价来源（抖音评价 / 天猫评价 / 小红书 / TikTok / 其他）
备案路径（普通化妆品备案 / 特殊化妆品注册 / 进口备案 / 暂无）
宣称支撑难度（无需评价 / 需文献资料 / 需人体功效试验）
预估成本
与我方价格带匹配（匹配 / 偏高 / 偏低）
与我方客群匹配（匹配 / 需教育 / 不符）
与我方 SKU 重合度（全新 / 部分重合 / 高度重合）
决策状态（待评 / 候选池 / 打样评估 / 已否决）
选品笔记

【二】《9 条规则阈值卡》——9/23 晚前
现在代码里的阈值是拍脑袋定的，评委一定会问"60% 这个数哪来的"。
需要你给依据，比如：
"过去 6 个月 TOP100 商品增速中位数 38%，取 1.6 倍≈60% 作为机会线"

待定的阈值（现在的默认值）：
· 窗口期：环比增速 ≥ 60
· 新品机会：上市 ≤ 90 天 且 增速 ≥ 100 且 销量 ≥ 1000
· 市场机会：同国家×二级类目 ≥ 3 条，中位增速 ≥ 60，正增长占比 ≥ 50
· 增速品类：同类目 ≥ 3 条，平均增速 ≥ 80
· 成分机会：成分出现在 ≥ 3 个商品，中位增速 ≥ 80

另外请你拍板一件事：
平台自己标了 MARKET_FLOW.韩国 = 'no'（TikTok Shop 韩国站没开通，
只有 Hwahae / Olive Young 的成分口碑名次，拿不到销量）。
我的建议是不要掩饰，主动在答辩里说出来——评委一看就知道我们懂数据边界。
你同意的话，麻烦写一句对外口径。
```

## 消息六 · 发给 AI 组（今天上午必发 · 用户调研模块开工用）

```
【用户调研模块开工 · 先帮我两个小忙，10 分钟的事】

我接了「用户调研」这块，主数据是自家店铺口碑。

① 脚本给我复用一下
平台源码注释里写了：_build/wb_douyin_usersound.py
这个文件能发我吗？我想直接跑它拉「抖音电商罗盘 · 体验 · 用户原声」，
不想重新造轮子。顺便带我跑一遍（登录态我这边有）。

② 加 6 行 ALIAS（不改可能我这批数据导不进去）
我看了 mapColumn 的逻辑，导入是按 ALIAS 别名表匹配的，
没匹配上的列会静默丢弃，不报错也不提示。目前这几个字段都不在表里：
差评原声 / 差评原因 / 好评关键词 / 差评关键词 / 评价来源 / 店铺类目

在 var ALIAS = { ... } 里补这几行就行：

'差评原声':   ['差评原声','差评原文','买家原话','差评内容','负评原声'],
'差评原因':   ['差评原因','差评标签','差评归因','差评原因分类'],
'好评关键词': ['好评关键词','好评词','正面词','好评首要'],
'差评关键词': ['差评关键词','差评词','负面词','差评首要'],
'评价来源':   ['评价来源','口碑来源','source'],
'店铺类目':   ['店铺类目','所属类目','经营类目']

③ 顺手提一个可能的错配
现在 '评分': ['评分','好评率','rating'] ——「好评率」是「评分」的别名。
口碑表里有独立的「好评率」字段（口径 = 好评数/评价数），
如果我把带「好评率」列的表导进去，值会被塞进评分字段。
建议把好评率从评分的别名里摘出来，否则我这边先不导这一列。

我今晚 21:00 参加集成，目标是口碑诊断不空白 + 「改良机会」规则有命中。
```
